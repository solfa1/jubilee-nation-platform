# Jubilee Nation Platform

A cloud-native church engagement platform built for **Jubilee Nation**.

The platform enables churches to:

- Register event attendees
- Collect testimonies
- Receive media uploads
- Manage visitor follow-up
- Project testimonies during services
- Build long-term community engagement

---

## Tech Stack

### Frontend

- Next.js 16
- TypeScript
- Tailwind CSS
- Shadcn/UI

### Backend

- Next.js Route Handlers
- Prisma ORM

### Database

- PostgreSQL

### Infrastructure

- Docker
- AWS
- Terraform
